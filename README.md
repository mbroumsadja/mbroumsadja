## 👋 À propos

Je suis **Mbroumsadja Emmanuel**, développeur **full-stack** à dominante **backend**, basé à **Garoua, Cameroun** 🇨🇲. Licencié en informatique de l'**Université de Garoua**, je poursuis aujourd'hui un **Master en informatique (parcours recherche)**.

Je conçois et déploie des **APIs, applications web et mobiles** pensées pour des contextes réels : plateformes universitaires, outils de gestion, sites vitrines pour des commerçants.

- ⚙️ **Ce que je fais** : APIs REST sécurisées (JWT, rôles), apps Next.js, bases SQL, déploiement cloud
- 🎓 **Ce qui m'anime** : des outils utiles pour l'éducation et la santé en Afrique
- 🧠 **Où je vais** : Machine Learning, data et recherche appliquée
- 🔁 **Ma méthode** : créer → innover → améliorer → automatiser
