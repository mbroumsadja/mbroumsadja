## À propos

Développeur full-stack, plutôt côté backend, basé à Garoua. Licencié en informatique de l'Université de Garoua, je prépare un master en informatique (parcours recherche).

Je construis des APIs, des applications web et des applications mobiles pour des besoins concrets : une plateforme d'archivage de cours pour une faculté de médecine, un outil de planification de stages, un site vitrine pour une boutique, un calcul de primes pour un centre médical.

Je m'oriente vers le machine learning et la data.
